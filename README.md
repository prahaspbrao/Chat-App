# 💬 ChatApp

A full-stack real-time chat application built with **React**, **Node.js**, and **MongoDB**.  
This project supports user authentication, private chats, and message persistence.  

---

## 🚀 Features

- 🔐 User authentication (Signup & Login)
- 💬 Real-time messaging using WebSockets
- 👥 Private and group chats
- 📨 Message history stored in MongoDB
- ⚙️ RESTful API for backend operations
- 🌐 Deployed with Nginx (Frontend + Backend)
- 🛠️ JWT authentication and bcrypt password hashing
- 📧 Email notifications via Resend

---

## 🏗️ Tech Stack

### **Frontend**
- React + Vite (or CRA)
- Context API / Zustand for state management
- Axios for API calls
- Tailwind CSS / MUI for UI components

### **Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT for authentication
- Bcrypt for password hashing
- Resend for email notifications
